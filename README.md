# CicadaPlugin (Paper / Leaf)

1. Push to GitHub, open Actions -> Build -> download `CicadaPlugin` (jar) and `cicada-pack` (zip). The SHA-1 of the pack is in the run summary.
2. Put the jar into `plugins/`, upload the pack zip to your hosting.
3. In `plugins/CicadaPlugin/config.yml` set `resource-pack.url` and `resource-pack.sha1`, then restart.
4. Texture: put `3180843.png` as `pack/assets/cicada/textures/item/cicada.png` (replaces the placeholder).
